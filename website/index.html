QUICK START

Up and running in 30 seconds

Zero manual configuration required. VibeCI automatically discovers your ecosystem, tools, and virtual environments.

STEP 1 & 2

Install & Verify with 1 Command

Run vibeci to trigger full multi-layer verification, or vibeci verify --diff for sub-second change verification on active edits.

TERMINAL 
# 1. Install globally via uv or pip
uv tool install vibeci

# 2. Run verification anywhere
vibeci verify --diff
STEP 3

Lock AI Agents into Self-Healing Loops

Running vibeci rule configures your AI assistant to run VibeCI after generating code, parse JSON diagnostics, and self-heal defects automatically.

TERMINAL 
# Configure Cursor, Claude Code, Copilot, & Antigravity
vibeci rule
MULTI-LAYER DEFENSE

5 Layers of Software Verification

AI models frequently introduce subtle configuration errors and security leaks. VibeCI catches what standard linters miss.

LAYER 1
🛡️

Static Health & Secret Leak Detection

Detects exposed OpenAI, Anthropic, Gemini, Stripe, and AWS credentials, along with undocumented environment variables referenced in code.

  • OpenAI, Claude, Gemini & Stripe keys
  • Missing .env.example references
  • Supports Vite, Astro, SvelteKit & Python
LAYER 2
⚙️

Production Build Verification

Confirms your project compiles and packages clean production artifacts before code leaves your computer.

  • npm run build, vite build, turbo
  • uv build, wheel & sdist verification
  • Catches bundler & TypeScript breakage
LAYER 3
🧪

Behavioral Test Suites

Executes your existing unit and integration suites without hanging in interactive watch modes.

  • Auto-detects pytest, vitest, jest
  • Smart selective execution in --diff mode
  • Enforces strict timeouts & non-interactive flags
LAYER 4
🚀

Runtime Boot & Smoke Testing

Boots application processes in sandboxed groups to probe HTTP health endpoints without leaving dangling processes.

  • FastAPI (uvicorn), Flask, Django auto-detection
  • Node / Next.js preview & start scripts
  • Probes readiness & validates HTTP 200
LAYER 5
⚖️

Honest Boundary Accounting

Unlike vanity tools that give fake 100% scores, VibeCI transparently reports critical systems that could not be verified.

  • Flags unexercised database connections
  • Reports live third-party payment/messaging APIs
  • Highlights missing browser E2E automation
